NasManager 设置

设置即时生效，无需重启。配置保存在 EXE 同目录的 settings.json。

WebUI 与 API 监听的端口，默认 8080。被占用会导致启动失败。
首次运行播种的管理员用户名，默认 admin。
留空 = 不修改（首次运行且留空则由系统随机生成，见 data/secrets/initial_admin_password.txt）。填写后下次启动即用此密码。
用户数据 / 索引 / 缩略图存放位置。默认位于程序数据目录下的 data\。
对外暴露的文件根，格式 key:绝对路径，多个用分号分隔。留空则仅“此电脑 + 个人空间”。
